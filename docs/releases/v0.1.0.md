# MoonDBC v0.1.0

MoonDBC is a MoonBit library and CLI for parsing a documented subset of DBC
files and encoding or decoding classic CAN integer signals.

## Features

- Parses message and signal definitions used by the supported DBC subset.
- Encodes and decodes Intel and Motorola DBC bit layouts.
- Supports signed and unsigned integer signals, with raw and physical values.
- Validates message and signal layouts before codec use.
- Provides `validate`, `inspect`, `decode`, and `encode` CLI commands.
- Includes project-authored synthetic DBC fixtures and file-based CLI tests.

## Limitations

- Supports classic CAN payloads up to 8 bytes.
- Extended CAN identifiers, multiplexing, floating-point DBC signal
  semantics, ARXML, and hardware CAN interfaces are not supported.
- This is a supported DBC subset, not a complete DBC implementation.
